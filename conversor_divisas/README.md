\# Conversor de Divisas -



Consola en Python que convierte un monto en ARS a USD (Oficial y Blue).



\## API

https://dolarapi.com/v1/dolares



\## Como usar

1\. Crear entorno: python -m venv .venv

2\. Instalar: .venv\\Scripts\\python.exe -m pip install -r requirements.txt

3\. Correr: .venv\\Scripts\\python.exe main.py



\## Ejemplo

Ingresá monto en ARS: 100000

+----------+--------+-------+------------------+

| Dolar    | Compra | Venta | Con 100000.0 ARS |

+----------+--------+-------+------------------+

| Blue     | 1545   | 1565  | 63.9             |

| Oficial  | 1500   | 1550  | 64.52            |

+----------+--------+-------+------------------+
